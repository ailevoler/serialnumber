# Biller logos

Put each biller's logo here and Pay Bills shows it automatically; until
then the tile shows the biller's initials.

File name = lowercase biller name with dashes, plus .svg, .png or .webp
(square, transparent background, ~200 x 200 px, under 30 KB):

| Biller (Aklan & Boracay)     | File name                         |
|------------------------------|-----------------------------------|
| PANTELCO                     | `pantelco.png`                    |
| KALIBO CABLE                 | `kalibo-cable.png`                |
| CONVERGE                     | `converge.png`                    |
| PLDT Home                    | `pldt-home.png`                   |
| Globe At Home                | `globe-at-home.png`               |
| Aklan Electric Cooperative   | `aklan-electric-cooperative.png`  |
| Boracay Waterworks Inc.      | `boracay-waterworks-inc.png`      |
| Caticlan Jetty Port          | `caticlan-jetty-port.png`         |

National ECPay / Bayad billers follow the same rule, e.g. `meralco.png`,
`pag-ibig-fund.png`, `iloilo-electric-more-power.png`. The list itself
lives in `includes/billers.php` (`national_billers()`).

Use logos you are allowed to display (from the biller or your ECPay /
Bayad partner kit).
